# Somov Detective

Сатирический линейный point-and-click квест в оригинальном сказочно-провинциальном мире **«Уезд №13»**.

## Статус

**Этап: pre-production / проектирование сюжета.**

Игровой код пока не пишем. Сначала полностью проектируем мир, карту, сюжет первой игры, персонажей, расследование, загадки, диалоги, UI/UX и список ассетов. Только после этого переходим к архитектуре и реализации в Godot.

## Что уже утверждено

- мир **«Уезд №13»**;
- город **Тихореченск**;
- условная провинциальная эпоха с визуальным ощущением 1970–1980-х и старой сказки;
- правило мира: сказочные существа всегда жили рядом с людьми;
- правило магии: **всякое чудо оставляет след**;
- главный герой — частный детектив **А. П. Сомов**, около 40 лет, бывший журналист;
- секретарь — **Клавдия Семёновна, кикимора**;
- общая география Тихореченска;
- визуальная карта Тихореченска v2;
- яркая сатирическая рисованная 2D-стилистика;
- базовое направление интерфейса классического point-and-click квеста.

## Производственный порядок

1. Мир и правила — **утверждено**.
2. География и общая карта — **утверждено**.
3. Полный сюжет первой игры — **текущий этап**.
4. Персонажи, которые требуются утверждённому сюжету.
5. Разбивка на акты и игровые сцены.
6. Граф расследования, улики и ложные версии.
7. Предметные и логические головоломки.
8. Диалоги и внутренние мысли Сомова.
9. Финальный UI/UX и asset list.
10. Техническая архитектура.
11. Разработка в Godot.

Принцип: **не придумываем постоянных персонажей ради количества**. Сначала понимаем сюжет и функции персонажей, затем решаем, кто из них становится постоянным жителем серии.

Первая игра должна стать фундаментом для следующих дел в той же вселенной.
