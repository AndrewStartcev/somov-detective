# Somov Detective

Сатирический линейный point-and-click квест в оригинальном сказочно-провинциальном мире.

## Статус

**Этап: pre-production / проектирование.**

До утверждения полного сюжета, карты, персонажей, игровых состояний и контент-плана **код не пишем**.

Сначала проектируем игру в обсуждениях, а зафиксированные решения переносим в `docs/`.

## Основной документ

- [`docs/GAME_BIBLE.md`](docs/GAME_BIBLE.md) — текущая концепция мира, героя, тона, структуры игры и список открытых вопросов.

## Базовый принцип производства

1. Мир и правила.
2. Персонажи.
3. Карта и локации.
4. Полный сюжет первой игры.
5. Головоломки, улики и зависимости.
6. Диалоги и юмор.
7. UI/UX и арт-пайплайн.
8. Только после этого — техническая архитектура и разработка в Godot.

Проект задуман так, чтобы первая игра стала фундаментом для следующих историй в той же вселенной.
