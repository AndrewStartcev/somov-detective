# 2. Решения, которые считаются каноном первой игры

1. Четверги **происходят**, но город их забывает.
2. К началу игры потеряно два четверга подряд.
3. Второй четверг Сомов уже провёл в расследовании и забывает собственную работу.
4. Книга учёта дней содержит семь древних якорей дней недели.
5. Удалён якорь `Четверг`.
6. Причина — поступок Фёдора Павловича Круглова.
7. Круглов не злодей и не обманывает Сомова.
8. Он хотел выиграть одни сутки из-за проверки котельной.
9. Сам забыл поступок после срабатывания эффекта.
10. Горыныч и бригада успели починить котельную ещё в первый четверг.
11. Комиссия фактически не закрывала котельную.
12. Круглов спрятал якорь в камере хранения вокзала.
13. Буров помнит четверг, потому что уехал из города до окончания суток.
14. Якорь возвращается в Книгу, память возвращается.
15. Финал не карает «злодея», а завершает человеческую историю ошибки.
16. Последний телефонный звонок Лешего тизерит возможное следующее дело в Старом лесу.

# 6. Следующая фаза

**Coding + asset production.**

Рекомендуемый старт не со всей игры сразу, а с vertical slice:

`Агентство → карта → Котельная №3 → улика → блокнот → autosave/load → возврат в Агентство`.

Vertical slice должен проверить:

- движение Сомова;
- hotspot;
- диалог;
- inventory;
- clue/fact;
- notebook;
- map;
- scene transition;
- save/load;
- основной визуальный pipeline.

После этого масштабируем систему на остальные акты.

Подробный порядок реализации: `TECH_ARCHITECTURE.md`.

# 7. Production rule после старта разработки

История больше не должна переписываться под удобство случайно написанного кода.

> **Код реализует утверждённую игру. Не игра подстраивается под первый вариант кода.**

Если техническая проблема требует изменения сценария, решение сначала фиксируется в docs, затем меняется реализация.
