# 2. Канон первой игры

Первая игра — **«Дело о пропавшем четверге»**.

В Тихореченске уже две недели подряд четверг происходит полностью, но после наступления пятницы жители теряют доступ к памяти о прошедших сутках. Документы, фотографии, работа и другие физические следы сохраняются.

Во второй забытый четверг Сомов уже начал расследование. В пятницу он забывает собственную работу и вынужден идти по своим вчерашним записям.

Причина связана с **Книгой учёта дней** и семью древними листами-якорями. Из Книги вынут якорь `Четверг`.

Фёдор Павлович Круглов, руководитель коммунальной конторы, во время областной проверки испугался возможной остановки Котельной №3 и последствий слишком рано подписанного акта готовности. Он хотел «купить одни сутки», спрятал якорь в камере хранения вокзала и собирался вернуть его утром. После наступления пятницы сам забыл собственный поступок.

Круглов не злодей и не ведёт двойную игру. Финальная ирония: Горыныч и бригада уже успели устранить неисправность, а комиссия разрешила продолжить работу.

Якорь возвращают в Книгу, память города восстанавливается. Первое дело полностью закрывается.

Последний телефонный звонок Лешего создаёт мягкий крючок на возможное следующее дело в Старом лесу.

# 3. Production scope

Первая игра использует **8 глобальных игровых узлов**:

1. Агентство Сомова.
2. Центральная площадь.
3. Редакция «Тихореченского вестника».
4. Котельная №3.
5. Коммунальная контора.
6. Городской архив.
7. НИИ прикладных явлений.
8. Тихореченский вокзал.

Рекомендуемый core: **14 уникальных backgrounds**. Повторные сюжетные сцены используют те же фоны с изменёнными NPC, props, hotspot states и диалогами.

Структура: **5 актов + 21 смысловая сцена + эпилог**.

Целевой обычный первый проход: примерно **90–120 минут**. Внимательное исследование и optional content могут увеличить время до 2–2.5 часов.

# 6. Детектив и головоломки

Главный дизайн-принцип:

> **Ключевой вывод подтверждается минимум двумя независимыми следами.**

Игрок не угадывает авторскую мысль и не попадает в необратимые тупики.

Основные задачи включают:

- собственные вчерашние следы Сомова;
- негативы редакции;
- сапог Горыныча;
- реконструкцию ремонта;
- точный архивный запрос;
- отсутствие `Четверга` в Книге;
- вчерашний пропуск НИИ;
- вывод о границе эффекта;
- вчерашнюю телеграмму;
- временную шкалу поездов;
- запись камеры хранения;
- квитанцию в подкладке пальто;
- открытие ячейки;
- возвращение якоря.

Не используем случайные кодовые замки, лабиринты, pixel hunting, нелогичные комбинации предметов, скрытые таймеры и обязательные reflex mini-games.

# 7. Побочный контент

`Самолётик` Пети и деда — **обязателен к производству, но необязателен для прохождения**. Его задача — показать, что потеряны не только рабочие сутки, но и личные человеческие воспоминания.

Дополнительно при нормальном production-бюджете:

- `Кто должен за хлеб?`;
- `Деньги за несуществующий день`;
- несколько ambient micro-events.

Optional content не хранит критические для main story улики.

# 10. Технический план

Код ещё не создан.

Архитектура закладывает отдельные слои:

`content → gameplay services → core services → platform facade → Local/Yandex/Pikabu adapters`.

Сохранения: **local-first + cloud sync + versioned state**.

Gameplay не вызывает SDK напрямую.

Яндекс и Пикабу подключаются отдельными адаптерами. Для Пикабу предусмотрен собственный backend cloud-save слой; platform secrets остаются только на сервере.

Диалоги и большая часть content state планируются data-driven, а stable IDs уже зафиксированы в `CONTENT_REGISTRY.md`.

# 12. Что НЕ блокирует старт кода

Можно дописывать во время content assembly без пересмотра архитектуры:

- атмосферные реакции Сомова на второстепенные предметы;
- дополнительные greetings/городские реплики;
- несколько ambient-шуток;
- конкретные музыкальные композиции;
- optional интерьер гастронома;
- optional набережную;
- полный дизайн Лешего и второй игры;
- название деревни;
- полную озвучку — сейчас не требуется;
- rewarded-рекламу — архитектурно поддерживается, но может отсутствовать в первой версии.
