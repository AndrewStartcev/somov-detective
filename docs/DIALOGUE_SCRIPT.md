# S01 — Агентство, утро

# Повторные разговоры

После каждого крупного открытия достаточно 1–2 новых коротких реплик у relevant NPC.

Принцип:

- Рогов после открытия Книги: шутит, что в газете дни пока печатают все семь;
- Горыныч после понимания механизма: спрашивает, оплачиваются ли забытые смены;
- Круглов после нахождения записи камеры хранения становится заметно тише;
- Листова после обнаружения якоря думает прежде всего о его состоянии;
- Мухин после доказательства Бурова удовлетворён экспериментально подтверждённой границей эффекта;
- Нина после финала может сказать: `Ячейку освободили. Четверг выдан владельцу.`

Эти реплики не открывают новые сюжетные ветки.
