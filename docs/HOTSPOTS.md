# HOTSPOTS / INTERACTIONS — «Дело о пропавшем четверге»

> Статус: **утверждённый pre-code план**  
> Версия: 1.0  
> Основа: `LOCATIONS.md`, `SCENES.md`, `PUZZLES.md`.

Документ определяет обязательные интерактивные зоны. Координаты и точные interaction points задаются уже после готовности конкретного фона, но смысл и state каждого hotspot известны заранее.

## Общие правила

- сюжетный hotspot всегда крупнее визуальной детали на touch;
- основное действие контекстное;
- после использования ключевого объекта реакция меняется;
- законченный puzzle не запускается повторно;
- ambient hotspot не влияет на main progression;
- неправильное применение предмета даёт короткое объяснение, не generic `Не могу`;
- не более 8–12 заметных hotspot на одном обычном фоне, чтобы игра не превращалась в hidden object.

# Подписи действий

Формат — глагол + объект, коротко:

- `Осмотреть календарь`
- `Поговорить с Роговым`
- `Посмотреть негативы`
- `Проверить журнал`
- `Осмотреть ремонт`
- `Открыть блокнот`
- `Перейти в хранилище`

Не использовать подписи вида `Нажмите сюда`.

# Состояния после завершения

После получения критической улики hotspot не исчезает бесследно. Его повторная реакция подтверждает уже известное:

> «Подпись моя. Второй раз проверять почерк не поможет.»

> «Ремонт свежий. Теперь я хотя бы знаю когда.»

> «Пустое место между Средой и Пятницей. Скоро исправим.»

Это делает мир устойчивым и не создаёт ощущения, что игровые предметы исчезают только потому, что квест закончился.

# Definition of Done для фона

До подключения background в production для него должны быть известны:

- walkable area;
- entry/exit points;
- interaction points персонажей;
- обязательные hotspot из этого документа;
- optional ambient hotspot;
- foreground occluders;
- отдельные изменяемые props;
- NPC staging positions;
- safe area для UI;
- mobile hitbox check.

Таким образом каждый фон можно собирать по спецификации без изобретения логики уже в Godot.
